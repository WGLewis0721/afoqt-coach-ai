# Quantitative knowledge (AR + MK)

No calculator. Scratch paper only. Quant composite = AR + MK. MK also feeds Pilot, CSO, ABM, and Academic.

## Arithmetic Reasoning (word problems)
Translate English → one equation, then compute.

### Distance / rate / time
`d = r t`
- Same direction: relative speed = difference.
- Opposite direction: relative speed = sum.
- Round trip: two segments, possibly different speeds. Average speed ≠ arithmetic mean if times differ.
  Average speed = total distance / total time.

### Work rates
If A does a job in a hours and B in b hours:
- Together: `1/a + 1/b = 1/t`
- Pipes filling and draining: add fill rates, subtract drain rates.

### Percent
- Percent of: `part = pct/100 * whole`
- Percent change: `(new - old) / old * 100`
- Successive discounts: multiply remaining factors. 20% off then 10% off = 0.8 * 0.9 = 0.72 of original.
- Increase then decrease of same percent does NOT return to start.

### Ratio and proportion
`a/b = c/d` → `ad = bc`
Scale recipes, maps, similar triangles, unit conversions this way.

### Mixtures
`value = amount * concentration`
All-in / all-out: `c1 v1 + c2 v2 = cf (v1+v2)`

### Simple interest
`I = P r t` with r as decimal, t in years.
Compound (if it appears): `A = P (1+r)^t`

### Unit conversions you should know cold
- 12 in = 1 ft; 3 ft = 1 yd; 5280 ft = 1 mi
- 16 oz = 1 lb
- 4 qt = 1 gal; 2 pt = 1 qt
- 60 s = 1 min; 60 min = 1 hr
- 100 cm = 1 m; 1000 m = 1 km
- 2.54 cm ≈ 1 in (only if a problem gives it)

### Integers and number sense
- Even * anything even = even; odd * odd = odd
- Remainder problems: divide, keep remainder, or use modular thinking
- Consecutive integers: n, n+1, n+2…
- Consecutive evens/odds: n, n+2, n+4…

## Math Knowledge (pure math)

### Order of operations
PEMDAS. Parentheses, exponents, multiply/divide left to right, add/subtract left to right.

### Fractions
- Multiply: numerators together, denominators together
- Divide: multiply by reciprocal
- Add/sub: common denominator
- Mixed number = whole + frac

### Decimals and percents
Move decimal two places for percent ↔ decimal.

### Exponents
- `a^m a^n = a^(m+n)`
- `a^m / a^n = a^(m-n)`
- `(a^m)^n = a^(mn)`
- `a^0 = 1` (a ≠ 0)
- `a^(-n) = 1/a^n`
- `(ab)^n = a^n b^n`

### Radicals
- `√(ab) = √a √b`
- `√(a/b) = √a / √b`
- `√a * √a = a`
- Rationalize denominator: multiply by conjugate if binomial.

### Algebra
Linear: `ax + b = c` → isolate x.
Quadratic: `ax^2 + bx + c = 0`
- Factor if easy
- Quadratic formula: `x = [-b ± √(b^2-4ac)] / (2a)`
- Discriminant `b^2-4ac`: +, 0, − → two, one, zero real roots

FOIL / binomial: `(x+a)(x+b) = x^2 + (a+b)x + ab`

Inequalities: flip the inequality when multiplying or dividing by a negative.

Absolute value: `|x| = a` → x = a or x = −a (a ≥ 0)

Systems: substitution or elimination.

### Functions and sequences
- Slope: `m = (y2-y1)/(x2-x1)`
- Point-slope: `y - y1 = m(x - x1)`
- Slope-intercept: `y = mx + b`
- Distance: `√[(x2-x1)^2 + (y2-y1)^2]`
- Midpoint: `((x1+x2)/2, (y1+y2)/2)`
- Parallel lines: equal slopes. Perpendicular: slopes negative reciprocals.

### Geometry — angles
- Full circle 360°. Straight line 180°. Right angle 90°.
- Vertical angles equal. Adjacent on a line sum to 180°.
- Triangle angles sum 180°.
- Parallel + transversal: corresponding equal, alternate interior equal, consecutive interior supplementary.

### Geometry — triangles
- Pythagorean: `a^2 + b^2 = c^2` (right triangle)
- Special rights:
  - 45-45-90: legs x, hypotenuse x√2
  - 30-60-90: short x, long x√3, hypotenuse 2x
- Similar triangles: corresponding sides proportional
- Area: `A = (1/2) b h`
- Equilateral area: `(s^2 √3) / 4`

### Geometry — other shapes
- Rectangle: A = lw, P = 2(l+w)
- Square: A = s^2, P = 4s
- Parallelogram: A = bh
- Trapezoid: A = (1/2)(b1+b2)h
- Circle: C = 2πr = πd; A = πr^2
- Arc length: `(θ/360) * 2πr`
- Sector area: `(θ/360) * πr^2`
- Rectangular box: V = lwh, SA = 2(lw+lh+wh)
- Cube: V = s^3, SA = 6s^2
- Cylinder: V = πr^2 h, SA = 2πr^2 + 2πrh
- Sphere: V = (4/3)πr^3, SA = 4πr^2
- Cone: V = (1/3)πr^2 h
- Pyramid: V = (1/3)Bh

Use π = 3.14 or leave in terms of π if choices do.

### Probability and counting (light)
- P = favorable / total
- Independent: multiply
- "And" vs "or" (add if disjoint)

### Statistics (light)
- Mean = average
- Median = middle when ordered
- Mode = most frequent
- Range = max − min

## Mental math shortcuts
- 15% = 10% + 5%
- Multiply by 25 = divide by 4, then * 100? Wait: n*25 = n*100/4
- Squaring teens: (10+a)^2 = 100 + 20a + a^2
- Estimate first so you can kill impossible choices.

## Common traps
- Area vs perimeter
- Radius vs diameter
- Forgetting to flip inequality
- Average of averages
- Percent of the wrong base
- 30-60-90 side mix-up (long leg is x√3, not 2x)
